# Finance Tracker

Десктопное приложение для учёта личных финансов в Германии. Импорт банковских выписок через ИИ, трекинг обязательств (включая Klarna-рассрочки), гибридный AI-чат, PIN-защита, уведомления о платежах.

## Стек

- **Electron 39** — десктопная оболочка
- **React 19** + **TypeScript** — UI
- **Vite** (electron-vite) — сборка
- **Tailwind CSS** — стили
- **Recharts** — графики
- **Framer Motion** — анимации
- **Zustand** — стейт-менеджмент
- **electron-store** — хранение данных в JSON-файле на диске
- **Ollama** (локально) — ИИ-парсинг, анализ, распознавание выписок

## Возможности

### Обзор (Dashboard)
- Карточки статистики за выбранный период: **К оплате** / **Оплачено** / **Lastschrift-Штрафы**
- Гистограмма за 6 месяцев с разбивкой по источникам (Sparkasse / Revolut / PayPal / Штрафы)
- Поиск по транзакциям (описание, источник, тип, дата)
- Таблица транзакций с удалением по одной и группировкой Sparkasse-пар (Rücklastschrift → Wiedergutschrift → Entgelt)
- Метка `Datenstand` (дата последнего импорта)
- Удаление всех транзакций с диалогом подтверждения
- Выбор периода: этот месяц / прошлый / позапрошлый / произвольный диапазон

### Импорт банковских выписок
- Вставка сырого текста банковской выписки → ИИ парсит в структурированный формат
- **Авто-определение банка**: Sparkasse / Revolut / PayPal / Klarna / Generic
- Ручное переключение банка
- Поле «дополнительные условия» (только на сессию)
- Умное определение готового формата — пропускает Ollama если данные уже структурированы
- Банко-специфичные промпты с few-shot примерами
- История импортов с удалением по батчам

### Обязательства
- Список регулярных платежей: подписки и ручные платежи
- **Периодичность**: ежемесячный / ежегодный / единоразовый
- Единоразовые обязательства отображаются только в месяце создания
- Отслеживание статуса по месяцам: `paid` / `unpaid` / `unknown` / `skipped`
- Статус `unknown` исключает обязательство из итоговой суммы и счётчика ожидающих
- **Перенос долга на следующий месяц** — ручная кнопка на каждой карточке:
  - Работает для **неоплаченных**: создаёт запись долга в следующем месяце + Mahnung-предупреждение
  - Работает для **оплаченных** (оплата с опозданием): фиксирует факт поздней оплаты
  - Ежемесячное оплаченное → объединяется с карточкой следующего месяца (разбивка сумм + Mahnung)
  - Не ежемесячное → создаёт отдельную запись в следующем месяце
  - Повторный перенос из одного месяца заблокирован
- **Mahnung-предупреждение** при переносе — предупреждает о возможном штрафе за просрочку
- Статистика: **Осталось оплатить** / **Оплачено в месяце** / **Ожидают оплаты** (с учётом перенесённых долгов)
- **Экспорт в PDF** — одной кнопкой: диалог сохранения → готовый PDF со всеми данными за месяц
- Предупреждения о платежах в ближайшие 5 дней
- Цепочки оплаты: `sparkasse_direct`, `paypal`, `vodafone_contract`, `klarna`, `other`
- Копирование обязательства в другой месяц (независимая копия с выбором месяца)
- **Связанные обязательства**: parent/child — оплата родителя покрывает дочерние
- Пользовательские секции — группировка и переименование (drag & drop)
- Undo/Redo — история действий (до 10 шагов)
- Поиск, фильтрация по статусу/типу и сортировка обязательств
- **Klarna-рассрочки** — интегрированы как обязательства с `billingChain: 'klarna'`:
  - Прогресс-бар взносов (X из Y платежей)
  - Автодеактивация при полной выплате
  - Парсер вставки Klarna-данных (магазин, сумма, взносы)
  - Поддержка типов: рассрочка / разовый платёж

### Гибридный AI-чат
- **Детерминированные ответы** — моментальные, точные ответы на типовые вопросы:
  - «Сколько я должен?» — сумма неоплаченных обязательств
  - «Какие не оплачены?» — список всех неоплаченных с суммами
  - «Какие оплачены?» — список оплаченных за текущий месяц
  - «Статус обязательств» — полная сводка по всем
  - «Свободные деньги» — баланс минус обязательства
  - «Сводка» — общий финансовый обзор
- **AI-фолбэк** — сложные вопросы и советы через Ollama (qwen2.5:3b)
- Очистка истории чата одной кнопкой
- Звуковое уведомление при получении ответа

### Новая запись
- Ручной ввод транзакции: дата, сумма, источник, тип, описание

### PIN-защита
- 4-значный PIN-код с SHA-256 хешированием и солью
- Блокировка на 5 минут после 3 неудачных попыток
- Включение/отключение через настройки

### Уведомления
- Системные уведомления о предстоящих платежах (3 дня)
- Алерты при критическом балансе
- Автопроверка при запуске и каждые 60 минут

### Диагностика ошибок
- Журнал ошибок с категориями: JavaScript, Ollama, валидация, IPC
- Фильтрация по категории, статусу, дате
- Автозахват необработанных исключений и промис-реджектов
- Toast-уведомления об ошибках в реальном времени
- Trail из последних 5 действий пользователя для отладки

## Типы транзакций

| Тип | Описание |
|---|---|
| `payment` | Zahlung (платёж) |
| `income` | Einnahme (доход) |
| `failed_debit` | Lastschrift-Rückgabe |
| `penalty` | Strafe / Gebühr |

Для Sparkasse: `sparkasseType` — `ruecklastschrift` / `wiedergutschrift` / `entgelt` / `normal`

## Источники

`Sparkasse` · `Deutsche Bank` · `Revolut` · `PayPal` · `Klarna` · `Vodafone` · `Other`

## Модель данных (AppData)

```typescript
AppData {
  transactions: Transaction[]        // все транзакции
  obligations: Obligation[]          // регулярные платежи (включая Klarna-рассрочки)
  obligationMonths: ObligationMonth[] // статус за каждый месяц
  importHistory: ImportRecord[]      // история импортов
  debtResolutions: DebtResolution[]  // урегулирования долгов
  accountBalances: AccountBalance[]  // балансы счетов
  financialSnapshot: FinancialSnapshot // финансовый снимок
  ollamaSettings: OllamaSettings     // URL, модель, список моделей
}
```

`ObligationMonth` хранит: статус, фактическую сумму, флаги переноса (`isCarriedOver`, `carriedFromYear/Month`, `carriedAmount`, `carriedPaid`).

`Obligation` для Klarna: `billingChain: 'klarna'`, `totalInstallments`, `originalTotal`.

## Требования

- **Node.js** 18+
- **Ollama** локально (`ollama serve`) — опционально, без него работает ручной ввод и импорт готового формата

## Установка и запуск

```bash
npm install
npm run dev
```

> **Если запускаешь из среды где установлена `ELECTRON_RUN_AS_NODE=1`** (например, VS Code terminal),
> используй: `env -u ELECTRON_RUN_AS_NODE npm run dev`
> (в `package.json` уже прописано автоматически)

### Сборка

```bash
npm run build:win    # Windows
npm run build:mac    # macOS
npm run build:linux  # Linux
```

Результат — в папке `dist/`.

## Privacy & Data

Finance Tracker — полностью локальное приложение. Никакие данные не отправляются в интернет.

- **Где хранятся данные:** `%APPDATA%/finance-tracker/config.json` (Windows), `~/Library/Application Support/finance-tracker/` (macOS), `~/.config/finance-tracker/` (Linux). JSON-файл с транзакциями, обязательствами, балансами.
- **Бэкапы:** автоматические каждые 30 минут в подпапку `backups/` того же каталога (последние 10).
- **Сеть:** единственный внешний вызов — HTTP-запросы к `http://localhost:11434` (локальный Ollama). Ни один сервер Anthropic / OpenAI / банка не задействован.
- **PIN:** опциональная защита входа, SHA-256 + соль, хранится в том же `config.json`.

Перед публикацией бэкапа или скриншотов куда-либо — помни, что в `config.json` лежит твоя реальная финансовая история.
